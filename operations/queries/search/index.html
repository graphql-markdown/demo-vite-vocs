    search

    Search folders, projects, and users from a single endpoint.

    search(
  query: String!
): [SearchResult!]!

    Arguments

    search.query ● String! non-null scalar

    Text matched against folder, project, and user names.

    Type

    SearchResult union

    A result returned from global workspace search.

    Example

    query SearchWorkspace($query: String!) {
  search(query: $query) {
    __typename
    ... on Folder {
      id
      name
    }
    ... on Project {
      id
      name
      status
    }
    ... on User {
      id
      name
      email
    }
  }
}
